# Bid & Format · 笔录竞标大会

> 百万笔录方案 · 无电脑攻坚 · 角色扮演

一个用于培训/工作坊的互动网页，模拟三组团队竞标「混乱笔录格式化」任务，通过抽签、方案填写、质询、投票、裁决，帮助参与者理解**流程设计**与**自动化思维**的差异。

## 🎯 使用场景

- 企业内训：流程优化、自动化意识培养
- 教学课堂：角色扮演、小组协作
- 团队建设：竞标决策模拟

## 🚀 在线访问

部署后访问：`https://你的用户名.github.io/bid-and-format/`

## 🎮 玩法说明

1. **抽签**：三组各点击 ⚡ 抽取身份（传统手工艺组 / 工具辅助组 / 流程自动化组）
2. **填写方案**：各组填写【工作内容】和【流程图】
3. **质询**：中间横幅会自动生成针对每组的预设质询语句
4. **投票**：点击投票卡为支持的方案投票
5. **裁决**：点击「宣布中标」，显示中标方案与理由
6. **重置**：点击「重新抽签 / 重置任务」开始新一轮

## 🧩 三种身份

| 身份 | 核心思路 | 时间预估 | 优势 | 隐患 |
|------|---------|---------|------|------|
| 🐂 传统手工艺组 | 逐份手工修改 | ~40分钟 | 零误差 | 易疲劳、怕标准变 |
| 🛠️ 工具辅助组 | 查找替换 + 格式刷 | ~25分钟 | 比手工快 | 模板错则全错 |
| 🤖 流程自动化组 | 样式模板 + 宏概念 | 10分钟设计 + 2分钟应用 | 标准变只改一处 | 无电脑仅推演 |

## 🔧 待改进清单（Roadmap）

以下是可以后期迭代的方向，按优先级排列：

### 高优先级
- [ ] **真实倒计时**：当前 15:00 是静态显示，可改为可启动/暂停的真实倒计时
- [ ] **本地存储**：用 `localStorage` 保存抽签结果和投票，刷新不丢失
- [ ] **移动端适配**：当前 `.group-card` 固定 330px，小屏需改为流式宽度
- [ ] **流程图导出**：支持将流程图导出为图片（html2canvas）或 Markdown

### 中优先级
- [ ] **质询语句可编辑**：当前预设质询是硬编码，可改为可编辑列表
- [ ] **投票防重复**：当前可无限投票，可加「每组限投一次」逻辑
- [ ] **多轮竞标**：支持多轮投票与淘汰机制
- [ ] **音效反馈**：抽签、投票、裁决时加入轻量音效

### 低优先级 / 锦上添花
- [ ] **深色/浅色主题切换**
- [ ] **自定义身份**：允许教师自行添加/修改身份卡
- [ ] **数据统计面板**：记录各组历史得分
- [ ] **国际化**：支持中英文切换
- [ ] **PWA 支持**：可离线使用

### 代码质量
- [ ] **拆分文件**：当前 HTML/CSS/JS 全在一个文件，可拆为 `index.html` + `styles.css` + `app.js`
- [ ] **消除全局函数**：当前大量使用 `window.xxx`，可改为模块化
- [ ] **增加注释**：关键逻辑（如抽签补齐规则）补充说明
- [ ] **无障碍**：增加 ARIA 标签、键盘导航支持
